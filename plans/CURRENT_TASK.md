# حالة أول MVP المحلي

**التاريخ:** 3 أكتوبر 2026  
**الحالة:** MVP محلي منفذ ومختبر وجاهز للعرض ضمن النطاق الذي اختاره المستخدم.  
**الخطوة المؤجلة باختيار المستخدم:** تفعيل مفاتيح Gemini وTelegram وتجربتهما حيًا حين يريد. اختار أيضًا الاكتفاء بالديمو المحلي الآن، فلا يُنشأ مشروع Supabase بعيد ولا نشر Vercel.

## المنجز في التطبيق

- متجر عربي/إنجليزي متجاوب مع RTL/LTR، صفحة عطر وملاحظاته وأحجامه، بحث وفلاتر، صور تجريبية أصلية وصوت افتتاحي اختياري بعد تفاعل.
- حساب عميل، ملف وعناوين ومفضلة وسلة مستمرة ودمج سلة الزائر، طلبات سابقة، واستعادة كلمة المرور.
- دفع عند الاستلام فقط مع عرض سعر موقع، كوبون، معاملة قاعدة ذرية للمخزون والطلب، ومنع تكرار الطلب بالمفتاح نفسه.
- اختبار تفضيلات العطر ونتائج حتى ثلاثة عطور متوفرة من مخزون المتجر بنسبة داخلية. Gemini يصوغ الشرح فقط عندما يوجد مفتاح؛ fallback عربي/إنجليزي عند غيابه أو فشله.
- لوحة إدارة بأدوار Manager وOrders Manager وProduct & Inventory Manager؛ تحرير منتجات ونوتات وصور ومخزون وطلبات وكوبونات واختبار وأسئلة وموظفين وهوية ومناطق شحن وإعدادات Telegram.
- outbox للإشعارات مع محاولة بعد حفظ الطلب وإعادة محاولة مجدولة؛ فشل Telegram لا يحذف الطلب.
- 24 عطرًا وبيانات seed، وسكربت ينشئ ثلاث حسابات موظفين محلية بكلمات مرور عشوائية في ملف مستبعد من التوزيع.

## دليل التحقق حتى الآن

- `npx supabase db reset --local`: نجح من قاعدة جديدة مع جميع migrations وseed، ثم نجح `npm run demo:staff`.
- `npm run lint` و`npm run typecheck` و`npm test` و`npm run build`: نجحت بعد آخر تعديلات التطبيق؛ 49 اختبار وحدة ناجح بلا تحذيرات lint.
- `RUN_SUPABASE_E2E=1 npx playwright test --reporter=dot`: **31 اختبار متصفح ناجح، واختبارا تأكيد البريد مؤجلان للإعداد الخاص بهما** على نسخة production محلية (`npm run start`) مع Supabase وMailpit محليين. تشمل الحساب والمفضلة والسلة وCOD والكوبون والمستشار واللغتين والأدوار ولوحة الإدارة ورفع الصورة ونشر منتج جديد.
- اختبار استعادة كلمة المرور الحقيقي: إرسال رسالة محلية، فتح الرابط، تغيير الكلمة، تسجيل الخروج والدخول بالكلمة الجديدة. أصلح مسار callback حتى لا يغيّر نطاق المتصفح ويفقد جلسة PKCE.
- شُغّل اختبارا تأكيد البريد مع `auth.email.enable_confirmations=true` مؤقتًا: رابط الرسالة يفتح حساب العميل، وسلة الزائر تنتقل للحساب وتبقى بعد إعادة التحميل. نجح 2/2؛ أُعيد إعداد الديمو إلى `false` ثم نجح اختبارا التسجيل المعتادان 2/2 بعد إعادة تشغيل Supabase المحلي.
- ضمن الاختبارات النهائية: الشاشات 360 و768 و1440px على المتجر والمنتج والمستشار ولوحة الإدارة والمنتجات، بالعربية والإنجليزية، دون overflow أفقي.
- فُحصت لقطتا الصفحة الرئيسية العربية يدويًا بعرض 1440px و390px من نسخة التشغيل المحلية؛ ظهرت الهوية والصورة والدعوة للتسوق وتنبيه الديمو بترتيب سليم.
- انتقال أسئلة المستشار يستخدم Motion بتأثير قصير ويحترم إعداد تقليل الحركة. عولج عرض صور المنتجات المرفوعة على Supabase المحلي في نسخة الإنتاج دون السماح لمحسّن صور Next.js بجلب عناوين محلية. اختبار النشر يتحقق الآن من تحميل الصورة فعليًا.
- نفد مخزون الحجم 30ml لعطر Amber Veil بعد تكرار الطلبات التجريبية؛ اختبارات الطلب تعيد تهيئته عبر API المدير عند الحاجة، فبقيت المجموعة الكاملة قابلة للإعادة دون مسح قاعدة الديمو.
- اختبار آخر وحدة: طلبان متزامنان أنتجا قبولًا واحدًا ورفضًا واحدًا؛ retry بالمفتاح نفسه أعاد الطلب نفسه. فحص SQL للمنتج الاختباري أظهر مخزونًا صفرًا، وحركة حجز واحدة، وطلبًا واحدًا.
- حماية آخر Manager من تعطيل دوره واختبارات منع Orders Manager وInventory Manager من واجهات Manager: ناجحة.
- إلغاء طلب COD مع كوبون: محاولة الإلغاء المكرر رُفضت، وحركة إعادة المخزون واحدة، وحالة استخدام الكوبون أصبحت `released` في قاعدة البيانات.
- بعد حذف عطر من المفضلة قدّمت الصفحة سابقًا بيانات قديمة رغم نجاح الحذف في القاعدة. فُرض الجلب الحديث لصفحة المفضلة، ونجح سيناريو الحذف وإعادة التحميل ثلاث مرات متوازية ثم ضمن حزمة المتصفح الكاملة.
- أُعيد تنظيف بيانات العرض العامة بعد الاختبارات: 24 عطرًا منشورًا، 3 مناطق شحن نشطة، كوبون نشط واحد، وإعداد Telegram التجريبي معطل. أُرشفت المنتجات التجريبية المنشورة وعُطّلت كوبونات الاختبار؛ لم تُمس سجلات الطلبات.
- أُنشئ أرشيف مصدر للتسليم مع فحص الأسماء: جميع ملفات التوثيق المطلوبة موجودة، ولا ملفات `.env.local` أو اعتماد الموظفين أو `node_modules` أو `.next` أو نتائج الاختبار.
- `npx supabase db advisors --local --type security` و`npx supabase db lint --local --schema public,private`: بلا مسائل. `npm audit --omit=dev`: صفر ثغرات بعد إزالة أداة shadcn CLI غير اللازمة من حزم التشغيل؛ تبقى تحذيرات audit في أدوات التطوير التابعة لـESLint فقط.
- هذه الأدلة محلية. لا تدل على إرسال Telegram أو Gemini حي لغياب مفاتيحهما.

## التفعيل المؤجل بعد MVP المحلي

1. حين يقرر المستخدم وضع `GEMINI_API_KEY` و`TELEGRAM_BOT_TOKEN` في `.env.local` ويضبط `chat_id` من لوحة Manager، اختبر شرح Gemini وإشعار طلب حقيقي ببيانات خيالية. لا تعرض fallback أو اختبارات المحاكاة كدليل اتصال حي. لا تركز على المفاتيح الآن بطلبه.
2. يبقى النشر البعيد والجدولة المنشورة خارج هذه المرحلة بطلب المستخدم.

## حدود ثابتة

لا WhatsApp، لا OpenAI API، ولا دفع إلكتروني. مفاتيح الخدمات لا تدخل المتصفح أو الأرشيف. لا تشغّل reset على مشروع بعيد أو production.
