# Maison Sillage — مشروع متجر العطور

تطبيق الديمو ووثائقه • 2 أكتوبر 2026

**الحالة: MVP محلي مكتمل ومختبر.** يعمل المتجر مع قاعدة Supabase محلية وبيانات عطور تجريبية وعمليات حسابات وسلة وطلب بالدفع عند الاستلام. تكامل Gemini وTelegram مهيأ في الكود مع اختبارات للمخرجات والفشل؛ أجّل صاحب المشروع ضبط مفاتيحهما والنشر البعيد. لا يُعد وصول الرسائل أو شرح Gemini الحي مثبتًا حتى تجربتهما لاحقًا بحسابات الديمو.

Maison Sillage اسم تجريبي قابل للتغيير من إعدادات المتجر. الهدف متجر فاخر بالعربية والإنجليزية يعمل على الهاتف والتابلت والحاسوب، مع مستشار عطري يرشح ثلاثة عطور متاحة ويشرح سبب توافقها مع تفضيلات الزائر.

## القرارات الثابتة

- Next.js + TypeScript + Tailwind CSS + shadcn/ui + Motion.
- Supabase لقاعدة البيانات والحسابات والصور، وVercel للاستضافة.
- محرك داخلي يحسب التطابق؛ Gemini API يصوغ الشرح فقط.
- الدفع عند الاستلام فقط؛ لا WhatsApp ولا OpenAI API ولا بوابة دفع إلكتروني.
- أدوار الإدارة: Manager، Orders Manager، Product & Inventory Manager.
- إشعارات الطلبات عبر Telegram، مع حفظ الطلب أولًا واستقلاله عن نجاح الإشعار.
- ديمو كامل ببيانات خيالية وعمليات حقيقية محفوظة، وليس واجهات بأزرار شكلية.

## ما تحتاجه للتشغيل

حاسوب عليه إصدار Node.js متوافق مع `package.json` وDocker Desktop وSupabase CLI. للعرض المنشور تحتاج مشروع Supabase مستقلًا وحسابات Google AI Studio وVercel وبوت Telegram وقناة خاصة. البريد التجريبي يعمل محليًا بخادم اختبار؛ العرض المنشور يحتاج إعداد إرسال بريد موثوق لتأكيد الحساب واستعادة كلمة المرور.

## تشغيل التطبيق محليًا

نفّذ `npm ci` ثم `npx supabase start`. انسخ `.env.example` إلى `.env.local` واملأ قيم Supabase المحلية والأسرار العشوائية كما يشرح [دليل النشر](docs/DEPLOYMENT.md). بعد ذلك نفّذ `npx supabase db reset --local` لإنشاء المخطط والبيانات، و`npm run demo:staff` لإنشاء حسابات الموظفين المحلية. أخيرًا نفّذ `npm run dev` وافتح `http://localhost:3000/ar` أو `/en`. ملف كلمات مرور الموظفين المحلي مستبعد من التوزيع؛ لا تضعه في المستودع أو الأرشيف.

أوامر التحقق: `npm run lint` و`npm run typecheck` و`npm test` و`npm run build`. اختبار Playwright يحتاج Chromium؛ ثبّته مرة واحدة بـ`npx playwright install chromium`. للاختبارات المتصلة بقاعدة البيانات المحلية، عيّن `RUN_SUPABASE_E2E=1` قبل `npm run test:e2e`.

إصدارات الأساس مثبتة في `package-lock.json`. إذا أبلغ SWC على Windows عن رفض ACL لمجلد cache في ملف المستخدم، عيّن `SWC_NATIVE_BINDING_CACHE` إلى مجلد cache محلي آمن تسمح أذوناته بالكتابة، ثم أعد الأمر. هذا إعداد بيئي محلي ولا يُحفظ داخل المشروع.

## تعريف «جاهز للعرض»

المستخدم يسجل، يتصفح باللغتين، يجيب عن الاختبار، يضيف منتجًا متاحًا، يستخدم كوبونًا ويطلب بالدفع عند الاستلام. يظهر الطلب في حسابه ولوحة الإدارة، ينخفض المخزون مرة واحدة ويصل إشعار إلى قناة الديمو. الموظفون لا يصلون إلى مهام خارج أدوارهم. تعطل Gemini أو Telegram لا يمنع الشراء. تمر اختبارات الصلاحيات والتزامن واللغات على نسخة منشورة.

الاسم والعملة ومناطق التوصيل افتراضات للديمو موثقة؛ قبل متجر تجاري فعلي تُراجع بيانات النشاط وسياسة الشحن والخصوصية والتكاليف مع صاحب المتجر.
