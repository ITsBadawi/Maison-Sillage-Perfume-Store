# نظام التصميم — Modern Editorial Luxury

## التوجه

أناقة فاتحة وهادئة: المنتج هو بطل الصورة، والعناوين واسعة وواضحة، والنوتات تقدم كقصة قصيرة. لا لمعان ذهبي كثيف أو واجهة داكنة كافتراض. تتطابق جودة العربية مع الإنجليزية، ولا تُقصّر النصوص العربية حتى تلائم قالبًا أجنبيًا.

## توكنات البداية

| Token | القيمة | الاستخدام |
|---|---|---|
| background | #F8F5EF | عاجي دافئ للخلفية |
| surface | #FFFFFF | البطاقات والنماذج |
| surface-muted | #EEE8DE | أقسام ثانوية |
| text | #292620 | النص الرئيسي |
| text-muted | #665E54 | الشرح الثانوي، مع اختبار التباين |
| accent | #806344 | زر/حد نشط وتفاصيل محدودة |
| accent-soft | #DDCCB1 | زينة وخلفية خفيفة لا نص صغير |
| border | #D9D0C4 | فواصل |
| success | #2F654B | النجاح |
| danger | #A43131 | الخطأ |

هذه قيم ابتدائية وليست شهادة إتاحة؛ اختبر كل زوج لون نص/خلفية. استهدف 4.5:1 للنص العادي و3:1 للنص الكبير ومكونات التحكم. أي accent يضبطه المدير يجب أن يجتاز الفحص أو يعود إلى قيمة صالحة.

## الخطوط والتخطيط

للعربية خط واضح مثل Noto Sans Arabic، وللعناوين الإنجليزية خط serif مثل Cormorant Garamond مع fallback نظامي. تُراجع تراخيص الخطوط وملفاتها قبل تضمينها، ويُفضّل self-host عبر Next font. لا تباعد أحرف اصطناعي بين الحروف العربية.

Body 16–18px، line-height العربية 1.75 والإنجليزية 1.6. H1 متجاوب 36–72px دون تجاوز عرض الهاتف. عرض المحتوى الأقصى 1280px، عمود النص نحو 65 حرفًا في الإنجليزية وما يقابله بصريًا بالعربية. مسافات 4/8/12/16/24/32/48/64/96px، radius 8–16px، ظلال خفيفة. لا glass effects خلف النص الأساسي.

شبكة المنتجات: 1 عمود عند الحاجة للشاشات الضيقة، عمودان من عرض يسمح ببطاقات مقروءة، 3 للتابلت الواسع و4 للديسكتوب. لا تصغّر النص لفرض عدد أعمدة. صورة المنتج بنسبة 4:5 وخلفية موحدة مع تفاصيل زجاج ولمعة مدروسة.

## الحركة

Motion فقط: hover 120–180ms، فتح قائمة/سلة 180–240ms، انتقال سؤال 250–350ms، كشف hero 500–700ms. opacity وtransform بدل تحريك مقاسات تسبب قفزات. مسافة انتقال 8–16px، بلا scroll hijacking أو مؤثرات تمنع الوصول للنص. عند prefers-reduced-motion عطّل الانتقالات المكانية وparallax واستخدم ظهورًا مباشرًا أو fade بسيطًا.

## الصوت الترحيبي

نغمة كريستال مرخصة أقل من ثانيتين ومستوى منخفض. لا تعتمد autoplay: تعرض عبارة اختيارية «ابدأ مع النغمة / Begin with sound» أو زر صوت صريح، فتعمل بعد النقر فقط ومرة واحدة في الزيارة الأولى المسموح بها. حفظ الاختيار محليًا، زر كتم دائم، وعدم التشغيل عند الرفض أو في النماذج. فشل تشغيل الصوت لا يمنع أي مسار.

## اللغة التحريرية

«اكتشف العطر الأقرب إلى ذوقك» / “Discover a scent that feels like you.”

«توافق مع تفضيلاتك: 87%» / “Preference match: 87%.”

الكتابة راقية ومحددة، دون وعود مثل «هذا يثبت أنك شخص غامض» أو «العطر المثالي مضمون». الأزرار العملية مباشرة: أضف للسلة، تابع الطلب، احفظ المنتج. لا تخفِ الرسوم خلف نصوص شاعرية.

## لوحة الإدارة

نفس الألوان مع كثافة معلومات أعلى. جداول وحقول واضحة، badges للحالات، زر حفظ ثابت يمكن الوصول إليه، تحذير عند مغادرة تعديل غير محفوظ. تأكيد واضح للإلغاء وأرشفة منتج وتغيير دور، مع ذكر أثر العملية. النوتات مقسمة top/heart/base، وvector عبر sliders بأرقام ووصف مبسط، وزر معاينة قبل النشر.

## الأصول المطلوبة أثناء التنفيذ

شعار نصي مؤقت، 24 صورة عطر خيالي مرخصة أو مولدة، 4–6 صور بيئات للاختبار، hero واحد للهاتف والديسكتوب، ملف نغمة مرخص. يسجل المصدر والترخيص في `public/assets/ASSET_LICENSES.md` عند إنشائها. لا تضم صور علامات تجارية دون حق استخدام ولا روابط صور عشوائية قابلة للكسر.
