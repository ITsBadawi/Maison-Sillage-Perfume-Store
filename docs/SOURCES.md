# المراجع الرسمية

تاريخ المراجعة: 2 أكتوبر 2026. هذه روابط لتثبيت اختيارات التكامل وتحديثها أثناء التنفيذ، وليست اعتمادًا على أسماء إصدارات في المحادثة السابقة. قد تتغير الحزم والخطط؛ تثبت إصدارات المشروع في M0 بعد اختبار التوافق.

| المصدر | ما الذي نستفيد منه؟ |
|---|---|
| [Next.js App Router](https://nextjs.org/docs/app) | تنظيم الصفحات ومكونات الخادم وRoute Handlers |
| [Tailwind مع Next.js](https://tailwindcss.com/docs/installation/framework-guides/nextjs) | إعداد CSS الرسمي للإصدار الحالي |
| [shadcn/ui مع Next.js](https://ui.shadcn.com/docs/installation/next) | تهيئة المكونات وإضافتها |
| [Motion for React](https://motion.dev/docs/react) | تكامل React والحركات |
| [next-intl App Router](https://next-intl.dev/docs/getting-started/app-router) | إعداد الرسائل والمسارات اللغوية |
| [Supabase SSR clients](https://supabase.com/docs/guides/auth/server-side/creating-a-client) | فصل عميل المتصفح والخادم والجلسات |
| [Supabase RLS](https://supabase.com/docs/guides/database/postgres/row-level-security) | سياسات الصفوف وحدود الوصول |
| [Supabase changelog](https://supabase.com/changelog) | مراجعة تغييرات ذات صلة قبل تثبيت التنفيذ |
| [Gemini structured outputs](https://ai.google.dev/gemini-api/docs/structured-output) | شكل JSON المنظم؛ تحقق التطبيق يبقى لازمًا |
| [Gemini models](https://ai.google.dev/gemini-api/docs/models) | اختيار نموذج متاح للحساب وقت النشر |
| [Telegram sendMessage](https://core.telegram.org/bots/api#sendmessage) | إرسال النص وخيارات التنسيق والاستجابة |
| [Vercel Cron usage and pricing](https://vercel.com/docs/cron-jobs/usage-and-pricing) | التحقق من التواتر والحدود حسب الخطة |

تم فتح وثائق التكامل أعلاه أثناء إعداد الخطة؛ رابط فهرس Supabase بصيغة Markdown لم يقبله قارئ الويب، لذلك راجعت صفحة changelog البديلة. لا توجد في هذه الحزمة دعوى تشغيل SDK أو اختبار API حي. قواعد التطابق والـoutbox والمال قرارات خاصة بهذا المشروع موثقة في ملفاتها، وليست اقتباسات من المزودات.
