# الواجهة وتجربة الاستخدام

## مسارات الصفحات

كل صفحة واجهة تبدأ بـ`/ar` أو `/en`. الجذر يوجه إلى العربية الافتراضية أو اللغة المحفوظة، والتبديل يحافظ على المنتج والسلة ومسار العودة بعد الدخول. API بلا prefix لغوي.

| المسار بعد locale | محتوى الصفحة |
|---|---|

## مكونات التجربة

- Header ثابت خفيف مع تبديل اللغة والبحث والسلة وحساب، وقائمة هاتف قابلة بلوحة المفاتيح.
- ProductCard بصورة بنسبة ثابتة واسم وسعر يبدأ من وحالة التوفر؛ hover لا يكون الطريق الوحيد للفعل.
- ProductGallery بصور محسنة وحجم محجوز لمنع قفز التخطيط، وبديل عند فشل الصورة.
- NotePyramid بثلاث طبقات مسماة، لا يعتمد على الرسم وحده.
- QuizOptionCard اختيار radio حقيقي؛ الصورة لا تستبدل النص. انتقال واضح بعد تأكيد الاختيار.
- ScentProfile على شكل أشرطة أفقية قابلة للقراءة مع الأرقام؛ لا حاجة لمكتبة رسوم كبيرة.
- RecommendationCard تعرض النسبة من الخادم، الاسم والصورة والسعر من الكتالوج، والشرح نصًا آمنًا.
- CartDrawer اختياري للمعاينة، وصفحة cart كاملة متاحة دائمًا.
- AdminDataTable مع بحث وفلاتر وترقيم؛ على الهاتف بطاقات أو scroll داخل الجدول بلا كسر الصفحة.

## الحالة والبيانات

URL للبحث والفلاتر والفرز، حالة React محلية للمظهر والخطوة، قاعدة البيانات للعمليات المستمرة. سلة الزائر localStorage للمعرفات فقط ثم merge بعد الدخول. Server Components للكتالوج وقراءات الحساب؛ Client Components للأزرار والنماذج والاختبار والحركة. optimistic UI مناسب للمفضلة مع rollback، وليس لتأكيد طلب أو تغيير مخزون دون جواب الخادم.

لكل صفحة حالات loading/skeleton وempty وerror وsuccess. لا spinner إلى الأبد؛ retry واضح ولا تكرار طلب شراء بمفتاح جديد بعد timeout. تعطيل زر الإرسال أثناء العملية مع بقاء حالة قارئ الشاشة. مراجعة البيانات كاملة قبل زر «تأكيد الطلب — الدفع عند الاستلام».

## اللغتان وإتاحة الاستخدام

`html lang=ar dir=rtl` أو `lang=en dir=ltr`. استخدم CSS logical properties مثل padding-inline، ولا تعكس صور المنتجات والشعارات. اعكس الأسهم الاتجاهية فقط. الأرقام والأسعار عبر Intl.NumberFormat والوقت عبر Intl.DateTimeFormat. الهاتف وSKU في مقطع LTR ضمن العربية. اختبر النص الطويل والترجمة في التابلت أيضًا.

كل label مرتبط بحقل، أخطاء أسفل الحقول وفي ملخص، focus ينتقل للخطأ أو عنوان السؤال، dialogs تحبس التركيز وتعيده، Escape يغلقها، تباين ملائم، tap targets لا تقل عن 44px. الحالة والنجاح لا يعتمدان على اللون وحده. اختبر zoom 200% وkeyboard وreduced-motion.

## الأداء وSEO

صور Next/Image بأحجام sizes ملائمة؛ تحميل hero الأساسي دون تحميل كامل المكتبة، وباقي الصور lazy. خطان كحد أقصى مع subsets ملائمة. قلل JavaScript في الصفحات العامة. أهداف بعد النشر والقياس: LCP ≤2.5s وCLS ≤0.1 وINP ≤200ms في ظروف اختبار موثقة، وليست نتائج مضمونة قبل التنفيذ.

Metadata مترجمة وروابط canonical وhreflang وsitemap للمنشور فقط وProduct structured data من السعر والتوفر الحقيقيين. الحساب والإدارة والنتائج الخاصة `noindex` وprivate cache. الديمو العام كله noindex افتراضيًا؛ تفعيله تجاريًا قرار لاحق. لا تضع نتائج توصية خاصة في Open Graph أو مشاركة عامة.
